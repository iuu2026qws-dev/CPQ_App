# 产品分析框架参考

## SWOT 分析法

### 概述
SWOT 是最经典的战略分析工具，从内部和外部四个维度全面评估产品。

### 分析维度
- **优势 (Strengths)**：内部优势、核心能力、独特价值主张
- **劣势 (Weaknesses)**：内部不足、待改进点、资源限制
- **机会 (Opportunities)**：市场机会、增长空间、新技术趋势
- **威胁 (Threats)**：竞争压力、市场风险、政策法规变化

### 输出：战略矩阵
| | 机会 (O) | 威胁 (T) |
|---|---|---|
| **优势 (S)** | SO 策略：利用优势把握机会 | ST 策略：利用优势规避威胁 |
| **劣势 (W)** | WO 策略：克服劣势抓住机会 | WT 策略：减少劣势应对威胁 |

## PEST 分析法

### 概述
从宏观环境角度分析影响产品的政治、经济、社会、技术因素。

### 分析维度
- **政治 (Political)**：政策法规、行业监管、税收政策
- **经济 (Economic)**：经济增长、消费能力、汇率波动
- **社会 (Social)**：人口结构、消费习惯、文化趋势
- **技术 (Technological)**：新技术发展、技术基础设施、创新速度

## Kano 模型

### 概述
Kano 模型用于对产品功能进行分类，帮助确定功能开发的优先级。

### 五类功能需求
1. **基本型需求（Must-have）**：用户认为理所当然的功能，不提供会极度不满
2. **期望型需求（Performance）**：用户明确期望的功能，提供越多满意度越高
3. **兴奋型需求（Attractive）**：用户意想不到的功能，提供后惊喜，不提供也无所谓
4. **无差异型需求（Indifferent）**：用户不关心的功能
5. **反向型需求（Reverse）**：提供后反而引起用户不满的功能

### 应用方法
1. 列出所有功能
2. 对每个功能通过正向和反向两个问题评估用户反应
3. 根据评估矩阵确定功能类型
4. 优先开发基本型和期望型需求，适度投入兴奋型需求

## 用户旅程地图

### 概述
从用户视角描绘完整的交互过程，识别痛点和改进机会。

### 旅程阶段
1. **意识阶段**：用户如何发现问题、了解产品
2. **考虑阶段**：用户如何评估和比较产品
3. **获取阶段**：用户如何开始使用产品
4. **使用阶段**：用户的核心使用体验
5. **忠诚阶段**：用户持续使用和推荐

### 分析要素
- 用户在每个阶段的行为
- 用户的目标和期望
- 触点（用户与产品交互的界面）
- 情绪曲线（满意度变化）
- 痛点和障碍
- 改进机会

## 竞品分析矩阵

### 概述
系统化对比竞品在多个维度上的表现。

### 对比维度
- 产品功能完整性
- 用户体验质量
- 技术能力和性能
- 定价策略
- 市场份额和用户规模
- 品牌影响力
- 渠道和生态
- 创新能力

### 矩阵模板

## 漏斗分析

### 概述
通过分析用户在每个转化节点的流失率，识别优化重点。

### 典型漏斗阶段
1. 曝光 → 访问
2. 访问 → 注册
3. 注册 → 激活
4. 激活 → 留存
5. 留存 → 付费
6. 付费 → 复购

### 分析步骤
1. 定义每个阶段的事件
2. 统计各阶段用户数量
3. 计算每步转化率和流失率
4. 识别最大流失环节
5. 制定针对性的优化策略

## 价值主张画布

### 概述
用于确保产品价值主张与客户需求之间的匹配。

### 两个部分
**客户画像：**
- 客户工作（Jobs）：功能性工作、社会性工作、情感性工作
- 痛点（Pains）：障碍、风险、不满
- 收益（Gains）：期望收益、惊喜收益

**价值地图：**
- 产品和服务：产品功能列表
- 痛点缓解方案：如何解决客户的痛点
- 收益创造方案：如何帮助客户获得收益

## HEUR 用户体验评估

### 概述
基于 Nielsen 的 10 条启发式原则，快速评估产品可用性。

### 10 条原则
1. 系统状态可见性
2. 系统与真实世界的匹配
3. 用户控制和自由
4. 一致性和标准
5. 错误预防
6. 识别而非回忆
7. 使用的灵活性和效率
8. 美学和简约设计
9. 帮助用户识别、诊断和恢复错误
10. 帮助和文档

### 评估方法
- 每个原则打分 1-5
- 列出违反原则的具体问题
- 给出严重程度评级（高/中/低）
- 提出改进建议

## 商业模式画布

### 概述
系统化描述和分析商业模式的工具。

### 九个模块
1. **价值主张**：为谁、解决什么问题、提供什么价值
2. **客户细分**：目标用户群体分类
3. **客户关系**：如何获取、维护和增长客户
4. **渠道通路**：如何触达和交付价值给客户
5. **收入来源**：盈利方式和定价策略
6. **核心资源**：关键资源（人力、技术、品牌等）
7. **关键业务**：核心业务流程
8. **重要伙伴**：合作伙伴和供应商
9. **成本结构**：主要成本构成

---

## 波特五力分析

### 概述
分析行业竞争态势的战略工具。

### 五种力量
1. **现有竞争者的竞争程度**
2. **新进入者的威胁**
3. **替代品的威胁**
4. **供应商的议价能力**
5. **买方的议价能力**

### 评估标准
每项力量评分：高/中/低，综合判断行业吸引力和竞争压力。

| 转化优化 | 漏斗分析 |
