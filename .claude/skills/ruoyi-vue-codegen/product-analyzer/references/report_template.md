# 产品分析报告模板

## 报告结构

| 章节 | 内容 | 建议篇幅 |
|------|------|----------|
| 1. 执行摘要 | 核心发现、关键建议、整体评价 | 300-500 字 |
| 2. 产品概述 | 定位、市场背景、目标 | 500-800 字 |
| 3. 用户分析 | 画像、需求、旅程地图 | 800-1200 字 |
| 4. 功能分析 | 结构、评估、Kano 分类 | 1000-1500 字 |
| 5. 竞品分析 | 矩阵、详细对比、差异化策略 | 1000-1500 字 |
| 6. SWOT 分析 | 优势、劣势、机会、威胁、战略矩阵 | 800-1200 字 |
| 7. 用户体验评估 | 流程、HEUR 评估、满意度 | 800-1000 字 |
| 8. 商业模式分析 | 画布、盈利模式、市场潜力 | 600-1000 字 |
| 9. 问题与机会 | 关键问题、改进机会、风险因素 | 600-800 字 |
| 10. 建议 | 短期、中期、长期 | 800-1200 字 |
| 11. 结论 | 总体评价、战略建议、下一步行动 | 300-500 字 |
| 12. 附录 | 数据来源、参考资料、分析方法 | 200-400 字 |

## 评分标准

### 产品综合评分（1-10 分）
| 维度 | 权重 | 评分 | 加权分 |
|------|------|------|--------|
| 功能完整性 | 20% | X/10 | X.X |
| 用户体验 | 20% | X/10 | X.X |
| 市场潜力 | 15% | X/10 | X.X |
| 商业模式 | 15% | X/10 | X.X |
| 竞争壁垒 | 10% | X/10 | X.X |
| 技术能力 | 10% | X/10 | X.X |
| 团队实力 | 10% | X/10 | X.X |
| **总分** | 100% | | X.X/10 |

### 评级标准
- ⭐⭐⭐⭐⭐ 优秀 (9-10) — 行业领先
- ⭐⭐⭐⭐ 良好 (7-8) — 有竞争力
- ⭐⭐⭐ 一般 (5-6) — 需要改进
- ⭐⭐ 较差 (3-4) — 存在明显不足
- ⭐ 极差 (1-2) — 需要重大调整
