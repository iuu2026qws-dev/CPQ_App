## 品牌主色

| 色阶 | Hex | 用途 |
|------|-----|------|
| 50 (soft) | `#E6F7F9` | Chip 背景、hover 底色 |
| 300 (border) | `#7FDCE4` | 边框强调 |
| 500 (主色) | `#17B5C5` | 品牌主色、CTA 按钮、链接、选中态 |
| 600 (hover) | `#0FA3B3` | 按钮 hover |
| 700 (active) | `#0A8B99` | 按钮 active |

## 组件预设

| 组件 | 规范 |
|------|------|
| 卡片圆角 | `24px` |
| 按钮 | Pill 胶囊 `48rpx`，`font-weight: 600` |
| 输入框 | 圆角 `16px`，`background: #F7F9FC` |
| 阴影 | `0 2px 8px rgba(10,21,32,0.04)` |
| TabBar 未选中 | `#8A93A3` |
| TabBar 选中 | `#17B5C5` |

## 间距（8pt 制）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64` px — 禁止 10/14/18/20

## 字重

`400 / 500 / 600` 三档 — 禁止 300/700/800

## 图标

使用 Lucide SVG + Sharp 渲染 PNG，严禁 PIL 手绘。每个角色独立图标：
- 患者：`heart-pulse`
- 医生：`stethoscope`
- 专家：`award`
- 学生：`graduation-cap`
