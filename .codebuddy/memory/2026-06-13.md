### 2026-06-13 晚上 — RECOMMENDING→CONFIGURING 状态转换修复
**用户反馈**：在智能推荐阶段点击"进入配置确认"，仍然无法正常工作（看不到配置确认卡片）

#### 二、模板编辑功能重新设计

**问题分析**：
- 模板有两种数据结构：`templateJson`（设计器生成的布局 JSON，含 sections/pageSettings）和 `templateContent`（渲染引擎使用的 HTML 模板）
- 之前两个系统独立运行：设计器保存 templateJson，但渲染使用 templateContent。用户通过设计器调整布局后，templateContent 不更新，导致设计和渲染脱节
- 不同模板类型的 templateContent 都一样是 HTML 占位符模板，类型只决定输出格式（STANDARD→HTML, PDF→PDF文件, WORD→.docx文件, EXCEL→.xlsx文件）

**修改**：
1. **TemplateDesigner.vue 增加 `buildTemplateHtml()`** — 将设计布局（sections）实时转化为含 `{{placeholder}}` 的完整 HTML 模板：
   - grid 区域 → CSS Grid 布局的 `<div>`，每个字段渲染为 `{{field.bindField}}`
   - table 区域 → `<table>` 带 thead，items 区域使用 `{{lines.table}}`（由后端动态填充行数据）
   - summary 区域 → 汇总表格含 `{{summary.*}}` 占位符
   - pageSettings（公司名/页脚/主题色）直接渲染到 HTML 中
   - 保存设计时同步调用 `updateTemplate` 将生成的 HTML 写入 `templateContent`
2. **TemplateManager.vue 编辑弹窗重新设计**：
   - 从单表单改为 **双 Tab 结构**：
     - Tab「基本信息」：模板名称、格式类型（带 `typeHint` 说明每种类型的用途和 templateContent 应包含的内容）、状态开关、备注
     - Tab「高级内容」：大号等宽字体 textarea（14行）+ 可折叠的「可用占位符参考」面板（列出 `{{quote.*}}`、`{{lines.table}}`、`{{summary.*}}` 全部占位符）
   - 新增 `editTab` ref（默认 'basic'），`typeHint` computed（根据 templateType 返回说明文字），`quotePlaceholders`/`summaryPlaceholders` 常量数组
   - 模板文本中的 `{{` `}}` 使用 HTML 实体转义（`&#123;&#123;` `&#125;&#125;`），避免被 Vue 编译器误解析

**设计理念解释**：
- **四种模板类型的 templateContent 统一为 HTML + 占位符**：无论是 STANDARD、PDF、WORD 还是 EXCEL，templateContent 都存储带 `{{placeholder}}` 的 HTML 文档
- 模板类型决定的是**输出格式**而非内容格式：STANDARD 直接返回 HTML，PDF 用 openhtmltopdf 将 HTML 转为 PDF，WORD 用 POI XWPF 生成 .docx，EXCEL 待后续实现
- **设计师是主要编辑入口**（面向普通用户），**高级内容 Tab 是备选方案**（面向懂 HTML 的高级用户）
- templateJson 和 templateContent 现在**通过 `buildTemplateHtml()` 保持同步**：每次保存设计都会更新 templateContent
