### CRM模块设计要点
- **业务关系**：客户(Account)→商机(Opportunity)→CPQ核心流程(配置→定价→报价)→合同(Contract)→订单(Order)
- **合同与订单两种模式**：模式A单项目制（1:1）、模式B框架合同多订单（1:N）
- **参照标准**：Salesforce CRM数据模型（Account/Opportunity/Order/Contract），简化适配制造业CPQ场景
- **新增5张表**：cpq_crm_opportunity（商机）、cpq_crm_contract（合同）、cpq_crm_order（订单）、cpq_crm_order_line（订单明细）、cpq_crm_activity（销售活动）
- **变更1张表**：cpq_account 新增 legal_representative（法人代表）、unified_social_credit_code（统一社会信用代码），address已存在
- **现有4张客户相关表**：cpq_account、cpq_channel、cpq_agreement_price、cpq_territory
- **商机6阶段**：PROSPECTING(10%)→QUALIFICATION(25%)→PROPOSAL(50%)→NEGOTIATION(75%)→CLOSED_WON(100%)/CLOSED_LOST(0%)
- **一级菜单**：CRM信息（User图标），二级：客户管理/商机管理/合同管理/订单管理
- **菜单ID范围**：50150-50179

### 2026-06-15 Bug修复：商机/合同/订单管理报"发生未知异常"

**根因**：SQL DDL脚本创建了但**未执行到数据库**。5张CRM表（cpq_crm_opportunity、cpq_crm_contract、cpq_crm_order、cpq_crm_order_line、cpq_crm_activity）在MySQL中不存在。

**后端日志确证**：
```
Table 'ruoyi_cpq.cpq_crm_contract' doesn't exist
Table 'ruoyi_cpq.cpq_crm_order' doesn't exist
```

**修复**：
1. SQL脚本修复：MySQL不支持`ADD COLUMN IF NOT EXISTS`语法，改用存储过程`add_column_if_not_exists`安全添加列
2. 执行`mysql -u root -p'Storm123@' Ruoyi_CPQ < sql/cpq_d13_crm.sql` → 5张表全部创建成功
3. 验证：`SHOW TABLES LIKE 'cpq_crm%'` 确认5张表存在，后端日志零CRM错误

**Lesson-learn对照**：
- 原则16（@AutoMapper缺失）：当前4个BO extends Entity（非TenantEntity），无@AutoMapper注解。但因项目全部使用Hutool `BeanUtil.toBean()` 而非MapStruct Plus `Convert.convert()`，所以@AutoMapper缺失**不是当前错误根因**。项目未引入MapStruct Plus，暂不强制要求@AutoMapper
- 闭环检查清单#6（JAR打包验证）：`mvn compile`通过不代表数据库已建表，必须验证DDL已实际执行到目标数据库
