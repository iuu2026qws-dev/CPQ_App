## 登录 401 "登录状态已过期" 修复 — 响应数据统一解包（2026-06-06 13:05）
- **根因**：RuoYi-Vue-Plus 后端所有接口返回 `{ code: 200, data: <业务数据> }` 包裹体，但 `store/user.ts` 直接取 `res.access_token` 拿到 undefined。token 存为 undefined → loadUserInfo() 无有效 token → 后端返回 401 → 触发"登录状态已过期"弹窗
- **方案**：用户建议不在 store 层做兼容，而是在 `request.ts` 响应拦截器统一解包，确保所有 API 调用方（包括未来代码生成器生成的代码）直接拿到纯业务数据
- **修改**：
  1. `request.ts` 成功分支新增智能解包：`if (body.data) return body.data` (自动剥离包裹体，兼容 blob/arraybuffer)
  2. `store/user.ts` 恢复直接属性访问（`res.access_token`、`info.permissions`）
  3. `api/auth.ts` login 函数加上 `isToken: false` header
  4. `.env.development` 去掉 `=` 两侧空格（Vite 不会 trim，会污染变量值）
- **skill 更新**：`ruoyi-lesson-learn/SKILL.md` 新增原则 6（响应拦截器必须统一解包）和检查项 11
- 关键决策：此方案确保未来代码生成器生成的模块代码无需任何二次解包适配
