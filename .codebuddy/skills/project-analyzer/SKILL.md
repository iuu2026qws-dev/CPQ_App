# Project Analyzer

## Overview

提供从需求到开发的全流程项目分析工具，包括竞品研究、功能拆解、需求细化、原型设计和开发清单生成。

## 工作流程

### 阶段 1：竞品分析

分析当前项目的竞品，包括：
- 竞品的功能模块和功能亮点
- 竞品的用户行为分析
- 竞品的市场定位和差异化机会

将分析结果保存至 `项目分析/1.竞品分析/竞品分析.md`。

### 阶段 2：功能清单

梳理当前项目的所有功能模块：
- 列出所有核心功能模块
- 说明每个模块的职责和使用场景
- 标注模块间的依赖关系

将结果保存至 `项目分析/2.功能清单/功能清单.md`。

### 阶段 3：需求分析

对需求进行细化和完整分析：
- 参考竞品分析结果（如有）和功能清单进行需求扩充和完善
- 列出每个需求的具体实现方案，包括技术实现、用户界面、用户交互说明
- 考虑用户使用场景，确保需求符合用户实际需求
- 在文档末尾给出功能需求的优先级和实现难易程度

将结果保存至 `项目分析/3.需求分析/需求分析.md`。

### 阶段 4：原型设计

基于功能清单和需求分析，设计完整的项目原型：

1. **调用设计技能**：使用 `ui-ux-pro-max`、`frontend-design`、`aesthetic` 技能辅助设计
2. **覆盖范围**：原型必须覆盖所有功能模块，不能仅包含关键页面
3. **格式**：使用 HTML 格式，每个原型页面包含完整的功能模块和用户交互
4. **核对**：完成后核对原型是否完全符合功能清单和需求分析
5. **索引**：生成 HTML 格式的索引文件方便查看

将原型保存至 `项目分析/4.原型图片/` 目录。

### 阶段 5：开发清单

生成开发相关的完整文档：

1. **开发文档**（`项目分析/5.开发清单/开发文档/开发文档.md`）：
   - 项目介绍、功能模块、用户行为
   - 技术实现、技术栈、数据库、服务器
   - 开发流程、开发人员、开发工具
   - Web 端使用 RuoYi-Vue 框架，App/小程序端使用 RuoYi-App 框架

2. **功能拆分**（`项目分析/5.开发清单/功能拆分/`）：
   - 将需求分析文档中的需求按功能模块拆分
   - 每个模块包含：名称、功能描述、实现方案、实现技术、实现步骤、参考原型

3. **开发周期**（`项目分析/5.开发清单/开发文档/开发周期/开发周期.md`）：
   - 项目的开发周期、时间、成本
   - 开发人员、开发工具
   - 开发流程和步骤

## 执行原则

1. **顺序执行**：严格按照竞品分析 → 功能清单 → 需求分析 → 原型设计 → 开发清单的顺序
2. **完整性**：每个阶段的输出必须完整，信息不能遗漏
3. **原型完整**：原型必须覆盖所有功能模块，不能仅生成关键页面
4. **文档清晰**：所有文档使用 Markdown 格式，原型使用 HTML 格式
5. **框架适配**：开发文档根据项目类型选择对应框架（RuoYi-Vue / RuoYi-App）

## 技能依赖

此技能需要调用以下技能：
- `ui-ux-pro-max` — UI/UX 设计优化
- `frontend-design` — 前端界面设计
- `aesthetic` — 视觉美学设计
